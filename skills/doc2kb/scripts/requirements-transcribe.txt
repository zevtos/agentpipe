# Opt-in speech-to-text tier for audio / video sources (extract_media.py).
#
# Install with:
#     python3 <skill_dir>/scripts/ensure_env.py --tier transcribe
#
# Installed into its OWN venv (<state>/transcribe/venv, Python 3.12), never the
# shared lightweight one: GigaAM pins onnx 1.19 / onnxruntime 1.23 (below what
# PyMuPDF 2.x needs) and torch wheels trail the newest CPython. After the
# pip step ensure_env runs `_asr.py setup`, which downloads the pinned models
# (HF revision + sha256): whisper.cpp ggml-large-v3 + silero VAD when
# `whisper-cli` is on PATH, otherwise the mlx-whisper / faster-whisper weights;
# GigaAM v3 e2e weights (449 MB, into <state>/transcribe/models/gigaam/);
# Parakeet v3 int8 (670 MB, into <state>/transcribe/models/parakeet/) on a
# CPU-only host, where the `fast` profile that reads it is the default.
#
# System tools (not pip): ffmpeg/ffprobe (required — decoding of every format),
# whisper-cli (`brew install whisper-cpp`; optional, the best base engine:
# Metal on Apple Silicon, `-mc 0` loop-proof decoding).
#
# Intel Macs: torch ≥ 2.6 publishes no x86_64 macOS wheels — the tier does not
# install there; subtitle tracks still extract without it.

# GigaAM (Sber, Russian ASR, MIT). PyPI ships only the v2 models; v3
# (v3_e2e_rnnt — punctuated and normalized, the most complete on hall audio)
# lives on GitHub main. Pinned to a commit, never a branch. Its own loader
# downloads weights from Sber's CDN (cdn.chatwm.opensmodel.sberdevices.ru,
# TLS certificate expired 2026-11-04), so `_asr.py setup` takes v3_e2e_rnnt
# from the official Hugging Face mirror instead (ai-sage/GigaAM-v3, branch
# e2e_rnnt, commit + sha256 pinned in _asr.py GIGAAM_HF) and builds the
# package's GigaAMASR from that state dict — transformers is not needed.
gigaam @ git+https://github.com/salute-developers/gigaam@7447938d791c4f3e643386ee22c33777004293a5
# torch ≥ 2.6: torch.load(weights_only=True) — how the Hugging Face state dict
# is read — is safe there (CVE-2025-32434). A legacy ~/.cache/gigaam checkpoint
# goes through GigaAM's loader, which unpickles it (weights_only=False) after
# its md5 check. < 2.11 = the line GigaAM main pins for its longform extra; its
# inference path needs none of the torchaudio I/O removed in 2.9.
torch>=2.6,<2.11
torchaudio>=2.6,<2.11
silero-vad>=6.2,<7
soundfile>=0.12,<1
numpy>=2,<3
huggingface_hub>=0.25,<2
# Parakeet TDT 0.6b v3 (NVIDIA, CC-BY-4.0) — the `fast` profile's engine for
# the non-Russian languages it knows. onnx-asr (MIT) is a numpy + onnxruntime
# runner for the ONNX export; onnxruntime itself arrives pinned with GigaAM
# (1.23), which onnx-asr accepts (>= 1.18.1). 0.12 is the API _asr.py uses.
onnx-asr>=0.12,<0.13
# Base engine when whisper-cli is absent: MLX on Apple Silicon, CTranslate2
# everywhere else (CPU int8 or CUDA).
mlx-whisper>=0.4.3,<0.5; sys_platform == "darwin" and platform_machine == "arm64"
faster-whisper>=1.1,<2; sys_platform != "darwin" or platform_machine != "arm64"

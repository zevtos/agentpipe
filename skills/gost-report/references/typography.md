# Типографика и экспорт в PDF

Режим для работ, где оценивают саму вёрстку: лабораторные по типографике и дизайну, рефераты, «красиво и строго». По умолчанию всё выключено, обычный отчёт собирается как раньше.

```python
from gost_report import Report

r = Report(title_page=False, typography=True, allow_dashes=True)
r.h1("Название")
r.subtitle("Подзаголовок: первая строка\nи вторая, разбитая по смыслу")
r.h2("Раздел")
r.text("Главное, что здесь есть, — **важная мысль** и *термин*: 400-430 л. с.")
r.save("работа.docx")
r.export_pdf()   # работа.pdf рядом с .docx, дефекты вёрстки печатаются в stderr
```

## Флаги

| Флаг | Что делает |
|---|---|
| `typography=True` | Неразрывные пробелы, кавычки и многоточие в прозе, разметка `**жирный**` и `*курсив*` в `r.text`, русский язык документа, автоперенос (кроме заголовков), интервалы вокруг заголовков, разрядка прописного h1, название PDF из первого h1 |
| `allow_dashes=True` | Только если тире прямо требует задание. Отключает замену тире и проверку `dashes`, в режиме типографики ещё меняет « - » на « — », «400-430» на «400–430». Без флага правило №1 скилла действует и при `typography=True` |

Флаги независимы. `typography=True` без `allow_dashes` годится и для обычного отчёта по ГОСТ: тире в нём не появятся.

Звёздочка с пробелами вокруг («2 * 3») остаётся знаком, литеральная пишется как `\*`. Незакрытое выделение и выделение через `$...$` падают с `ValueError`.

## Какие правила применяются

**Знаки.** Дефис в составных словах («twin-scroll»), короткое тире без пробелов в диапазонах («400–430»), длинное тире с пробелами между словами, неразрывный пробел перед ним, «ёлочки» как основные кавычки и „лапки“ как вложенные.

**Неразрывные пробелы.** После предлогов, союзов и частиц короче четырёх букв и нескольких длинных (`SHORT_WORDS` в `scripts/typography.py`), перед «же», «ли», «бы», между числом и единицей («3,0 л», «100 км/ч»), в «BMW 340i», «Stage 1», «рисунке 3», в инициалах. Узкий неразрывный: «л. с.», «т. е.», «А. С. Пушкин». Предлог после числа не клеится: иначе «от 326 до 387 л. с.» стала бы одной неразрывной цепочкой и разорвала бы соседнюю строку.

**Заголовки.** Отступ сверху втрое больше нижнего, чтобы заголовок читался как часть своего текста. Одинарный интервал, без переносов, не отрываются от следующего абзаца. Прописной h1 с разрядкой 5 % кегля.

**Выделение.** Два средства на два смысла: полужирный для главной мысли (контраст), курсив для термина в месте определения (нюанс). Цвет, подчёркивание и смешанные способы не нужны.

**Абзац.** Выключка по ширине только вместе с переносами, иначе в строках появляются дыры. Не больше двух переносов подряд в Word. Висячие строки подавляются.

Кегль, интервал и поля остаются из профиля (`references/profiles.md`).

## Как собирается PDF

`r.export_pdf()` вызывает LibreOffice со своим профилем в state-dir скилла (`<state>/lo-profile`), установленный LibreOffice и его настройки не меняются. Что в этом профиле и зачем:

- русский словарь переносов: в сборке LibreOffice для macOS его нет. Скачивается один раз, закреплён коммитом и sha256. Без сети PDF соберётся без переносов, с предупреждением;
- `UseVariableWidthNBSP`: по умолчанию неразрывный пробел в LibreOffice фиксированной ширины (tdf#41652), и рядом с растянутыми пробелами остаются плотные «в 2015». Word такие пробелы растягивает сам;
- на macOS свой `FONTCONFIG_FILE`: иначе `--headless` подменяет Times New Roman на Liberation Serif.

Конвертируется временная копия .docx, в которой WORD JOINER запрещает перенос внутри «400–430» и «АИ-98». В самом .docx этих символов нет, в Word такие диапазоны переноситься могут.

Word сознательно не используется: на macOS его песочница при сохранении в новую папку показывает модальный диалог «Grant File Access», и автоматический запуск зависает. Из Word можно сохранить PDF вручную, .docx для этого готов.

Нужен LibreOffice (`brew install --cask libreoffice`, `sudo apt install libreoffice-writer`) или путь в `GOST_REPORT_SOFFICE`.

## Проверка готового PDF

После экспорта `check_pdf` разбирает PDF через poppler (`pdftotext`, `pdffonts`) и печатает предупреждения. Они не блокируют сборку, без poppler проверка пропускается, отключается через `r.export_pdf(check=False)`.

| Код | Что нашла |
|---|---|
| `hanging-word` | Строка кончается предлогом или союзом |
| `broken-range` | Перенос внутри «400–430» или «5-ю» |
| `dash-at-start` | Строка начинается с тире |
| `wide-gap` | Пробел шире 0,75 кегля (три нормальных), дыра в строке |
| `hyphen-run` | Три переноса подряд |
| `runt` | Концовка абзаца из одного слова или короче 10 % строки |
| `widow`, `orphan` | Концовка абзаца в начале страницы, первая строка абзаца в конце страницы |
| `font`, `font-not-embedded` | Подмена шрифта профиля, невстроенный шрифт |

Текст после проверки стоит вычитать глазами: `wide-gap` может остаться там, где длинная неразрывная цепочка не помещается в строку и без правки текста её не убрать.
